Crafti as an iPhone and iPad app

Put everything in this folder on a secure (https) website, keeping the files together:
  index.html, manifest.webmanifest, sw.js, the icons folder (and .nojekyll for GitHub Pages).
Then share the address. On an iPhone or iPad, open it in Safari, tap Share, then Add to Home Screen.

To update: replace index.html (and sw.js) with the new versions. Phones pick up the new
version the next time the app is opened with an internet connection.

See the install guide (.docx) for step-by-step hosting on GitHub Pages or Netlify.
